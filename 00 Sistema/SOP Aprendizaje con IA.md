# SOP — Aprendizaje con IA

## Objetivo

Usar Claude, ChatGPT, Gemini u otros LLMs como:
- mentor técnico
- sistema de revisión
- simulador de entrevistas
- acelerador de aprendizaje
- generador de conexiones entre áreas

---

## Flujo diario ideal

### 1. Inicio de rutina

```
Rutina diaria:
Áreas: BI / Automatización / Ingeniería Industrial

Objetivo: mejorar empleabilidad BI + IA

Quiero:
- 3 a 5 conceptos importantes
- conexiones entre áreas
- ejemplos reales
- mini ejercicios
- preguntas tipo entrevista
- aplicación a proyectos reales
```

### 2. Aprendizaje
El LLM debe entregar: conceptos clave, explicaciones, relaciones, ejemplos, ejercicios, errores comunes.

### 3. Captura rápida
Documentar en Daily Note o Nota de Curso. No organizar perfecto, solo capturar.

### 4. Extracción de conocimiento
Si un concepto aparece varias veces o conecta áreas → crear nota atómica en `04 Knowledge`.

> **Regla de atomicidad (la unidad es la IDEA, no la sesión):** una sesión de estudio que cubre varias ideas produce **varias notas atómicas** (+ un hub corto si hace falta), no una mega-nota con todo lo visto. Profundizar un tema existente = **nota hija nueva** o sección `## Evolución` — nunca anexar "Profundización" al cuerpo. Señal de alarma: nota >120 líneas o título con "A, B y C". (Lección de la cirugía BRO 2026-07-11 en `Temas/`.)
