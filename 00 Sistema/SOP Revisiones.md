# SOP Revisiones

## Qué es
Es el proceso para auditar el vault y mantenerlo sano.

## Para qué sirve
Sirve para:
- detectar notas huérfanas
- detectar duplicados
- detectar MOCs faltantes
- detectar notas demasiado largas
- comprobar si los objetivos siguen vigentes
- revisar si los hábitos acompañan los objetivos

## Flujo CE-RE-BRO
### C — Conectar
- notas aisladas
- links faltantes
- temas que deberían relacionarse

### RE — Reagrupar
- tags duplicados
- nombres inconsistentes
- propiedades repetidas
- estructura redundante

### BRO — Descomponer y optimizar
- notas excesivamente largas
- conceptos mezclados
- archivos que deberían partirse
- estructuras que crecieron sin control y pueden simplificarse

## Cuándo revisar
- semanalmente: revisión ligera
- mensualmente: revisión de patrones
- trimestralmente: revisión de objetivos y previsiones
- semestralmente: revisión de valores y principios

## Qué revisar
- diario
- hábitos
- proyectos
- index
- MOCs
- notas evergreen
- notas modelo mental
