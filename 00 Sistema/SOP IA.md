# SOP IA

## Qué es
Este SOP explica cómo usar ChatGPT, Claude, Gemini, NotebookLM, Claude Code u otras herramientas compatibles dentro del vault.

## Para qué sirve
- estudiar
- resumir
- comparar marcos
- auditar notas
- proponer cambios
- generar borradores
- detectar duplicados
- crear estructura

## Cómo trabajar con IA
1. Dale contexto claro.
2. Dale el archivo o la nota correcta.
3. Pídele una salida concreta.
4. Pídele que proponga, no que borre.
5. Revisa tú el resultado.
6. Integra solo lo útil.

## Qué pedirle normalmente
- resúmenes
- auditorías
- matrices comparativas
- detección de huecos
- propuestas de conexión
- borradores de SOP
- explicaciones sencillas

## Qué NO hacer
- no pedirle que adivine
- no pedirle que reorganice todo sin criterio
- no dejarla decidir sola
- no usarla para duplicar contenido

## Criterio de salida
La salida debe ser:
- clara
- accionable
- sin ruido
- fácil de entender para otra persona
