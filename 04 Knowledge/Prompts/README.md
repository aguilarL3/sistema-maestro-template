# Prompts

Catálogo de prompts versionados — reutilizables, auditables, conectados.

## Qué se guarda aquí
- Una nota por prompt usando `[[Plantilla Prompt]]`.
- Naming: `Prompt - Nombre descriptivo.md` (ej. `Prompt - Búsqueda Web Estructurada.md`).
- Estructura plana (sin subcarpetas). La organización por caso de uso y por técnica vive en [[MOC - Prompt Engineering]].

## Qué NO se guarda aquí
- Apuntes de clase → `04 Knowledge/Cursos/{Curso}/`.
- Notas atómicas sobre técnicas (Role prompting, Structured output, etc.) → `04 Knowledge/Temas/`.

## Convención de versionado
Cuando el prompt viene de una clase y se mejora:
- **v1.0** — versión original (tal cual de la clase).
- **v2.0** (o superior) — versión mejorada por Claude/usuario, con justificación de cambios.

Ambas conviven en la misma nota, sección **📝 Prompt**. La justificación va en **🔄 Iteraciones / Versionado**.
