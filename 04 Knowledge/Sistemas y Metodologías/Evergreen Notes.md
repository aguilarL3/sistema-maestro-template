# Evergreen Notes

## Qué es
Una nota viva que crece contigo y no queda congelada.

## Qué problema resuelve
Evita que el conocimiento se vuelva una captura muerta que nadie vuelve a leer.

## Señales de una buena evergreen note
- se revisa
- se actualiza
- se conecta
- se enriquece con tiempo
- conserva utilidad futura

## Qué adoptamos en este vault
- notas con campo de evolución
- revisión periódica
- preguntas de mejora
- crecimiento acumulativo

## Relación con otros marcos
- se parece a las notas modelo mental de Cerebro Digital
- se apoya en Zettelkasten
- se mantiene con revisiones

## Uso en este vault
Se usa para conocimiento que vale la pena madurar con los años.
