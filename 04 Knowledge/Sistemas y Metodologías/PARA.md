# PARA

## Qué es
PARA significa Projects, Areas, Resources, Archives.

## Qué problema resuelve
Ayuda a clasificar información de forma simple para saber dónde vive cada cosa.

## Las 4 partes
### Projects
Iniciativas con principio y fin.

### Areas
Responsabilidades continuas que no “terminan”.

### Resources
Material de consulta o referencia.

### Archives
Lo terminado o lo que ya no usas.

## Qué adoptamos en este vault
- Projects → `03 Proyectos`
- Resources → `06 Raw`
- Archives → `99 Archivo`
- Areas → como clasificación transversal, no como carpeta infinita

## Qué no adoptamos
No convertimos el vault en una taxonomía rígida de carpetas.

## Relación con otros marcos
- conecta con GTD porque ayuda a clasificar
- conecta con Zettelkasten porque puede enlazarse
- conecta con Karpathy porque separa fuentes y wiki

## Uso en este vault
PARA se usa como lente para decidir dónde vive una información.
