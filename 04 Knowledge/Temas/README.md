# Temas

Notas atómicas conceptuales — una idea por nota, reutilizable, enlazable.

## Qué se guarda aquí
Notas atómicas sobre conceptos, técnicas, definiciones o modelos que aparecen 3+ veces en distintas fuentes, conectan áreas o tienen alto valor práctico.

## Ejemplos de conceptos que viven acá
- BI / IA / Automatización / Inglés / Finanzas / Salud (como dominios)
- Conceptos concretos: `Role prompting`, `Webhook`, `KPI`, `ETL`, `Backlink`, `Anatomía de un prompt de búsqueda`

## Qué NO se guarda aquí
- Apuntes de clase enteros → `04 Knowledge/Cursos/{Curso}/`.
- Prompts completos versionados → `04 Knowledge/Prompts/`.
- Metodologías y sistemas (GTD, PARA, Zettelkasten, etc.) → `04 Knowledge/Sistemas y Metodologías/`.
- Modelos mentales transversales → `04 Knowledge/Modelos Mentales/`.
